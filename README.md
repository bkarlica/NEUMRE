# NEUMRE

Repozitorij sadrži laboratorijske vježbe i timski projekt iz predmeta **Neuronske mreže**.

## Sadržaj

- **[MRI projekt](MRI projekt)**: klasifikacija tumora mozga iz MRI slika pomoću konvolucijskih neuronskih mreža (EfficientNet, ROI ekstrakcija). Timski projekt, Python, PyTorch, TensorFlow, OpenCV.
- **[Labosi](Labosi)**: laboratorijske vježbe u Pythonu (Jupyter Notebook): model neurona i asocijativna memorija, perceptron i LMS algoritam, višeslojni perceptron i SVM, rekurentne i konvolucijske mreže.

Detaljniji opis nalazi se u README datoteci unutar svake mape.
